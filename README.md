# #IoMiMuovoACasa

Platform for guided physical exercises at home — a collection of video-based workout programs categorized by age group and activity type.

## 🏠 About

This project provides free exercise videos for people staying at home, organized by:
- **Age groups**: 0-3 years, 3-5 years, 6-12 years, adults, seniors
- **Activity types**: Balance, stretching, aerobics, neurodevelopmental exercises, rehabilitation
